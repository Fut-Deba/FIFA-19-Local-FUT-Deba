FUT DEBA LAUNCHER ASSETS

The distributed launcher uses original, unbranded artwork generated for FUT
Deba. It contains no real-player likeness, club mark, sponsor, EA SPORTS mark
or FIFA logo.

- futdeba-hero-v2.png: fictional footballer home-page hero artwork
- futdeba-brand-v2.png: original football-and-orbit sidebar emblem
- launcher-icon-v3.png: original FUT Deba launcher window icon
- launcher-icon-v3.ico: Windows shortcut icon

The older Dybala and owner-supplied prototype references are source-only and
must not be copied into a release package.
