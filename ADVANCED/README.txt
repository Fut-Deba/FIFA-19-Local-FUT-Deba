This folder holds tools most testers never need. Use FUT_DEBA_LAUNCHER.cmd
in the package root for every normal session, including the first one.

PLAY_WITHOUT_LAUNCHER.cmd starts a Local FUT session without the launcher
window. Pass RTG to start the separate Road to Glory account.

CLEANUP_OLD_REDIRECTS.cmd removes FIFA 19 redirect lines from the Windows
hosts file, including those of other offline FUT tools, and puts back the
lines a FUT Deba session had set aside. Run it only when a message asks for it.

RTG_ACCOUNT_MODE opens the launcher with the separate Road to Glory account
preselected, and can reset that account after a verified backup.

TEST_CHECKLIST.md and BUG_REPORT_TEMPLATE.md are for beta testers.
