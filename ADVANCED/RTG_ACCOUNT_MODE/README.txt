This folder contains the optional Road to Glory account launcher.

PLAY_RTG_ACCOUNT.cmd opens the FUT Deba launcher with the separate Road to
Glory profile preselected. Normal and RTG progress use different databases.
The isolated v1 profile is not part of this validation pass.

RESET_RTG_ACCOUNT.cmd requires the exact RESET RTG confirmation and creates an
automatic verified backup before resetting only the selected build's RTG save.
